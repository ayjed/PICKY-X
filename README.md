
# PICKY X

Picky X is a mobile card-matching game built with Flutter and Dart.

The project focuses on interactive gameplay, responsive interfaces, and a smooth user experience.


## How to Play

Picky X is a memory-matching game designed to test your concentration and recall.

1. Tap a face-down card to reveal its symbol.
2. Select another card to find its matching pair.
3. Matching cards remain revealed.
4. If the cards do not match, remember their positions and try again.
5. Continue matching pairs to complete the challenge.

Try to finish with fewer moves and improve your personal best.

## Getting Started

1. Clone this repository:

   git clone https://github.com/ayjed/PICKY-X.git

2. Navigate to the project directory:

   cd PICKY-X

3. Install dependencies:

   flutter pub get

4. Run the application:

   flutter run
